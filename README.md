## 📚 Study Rule

1. **『코딩 테스트 합격자 되기: 자바 편』**을 중심으로 학습합니다.
2. 무리한 양보다 **지속 가능한 풀이 습관**을 우선합니다.
3. 문제를 풀고 코드와 함께 풀이 내용을 Markdown으로 남깁니다.
