## 학습 방향

- **정확하게** — 조건과 경계값을 확인하고 시간·공간 복잡도를 계산합니다.
- **스스로** — 해설을 참고했다면 다시 풀어 내 코드로 설명합니다.
- **꾸준하게** — 푼 개수보다 다시 풀 수 있는 문제를 늘립니다.

## 저장소 구성

| 경로 | 용도 |
| :-- | :-- |
| `C++/` | 앞으로 백준허브가 생성할 C++ 풀이 폴더 (첫 업로드 시 생성) |
| [Java/](./Java) · [MySQL/](./MySQL) | 기존 자동 업로드 풀이 |
| [notes/](./notes) | 오답·복습 기록과 개인 해설 |
| [templates/](./templates) | C++ 코드 템플릿 |
| [docs/](./docs/repository-guide.md) | 폴더 규칙과 백준허브 설정 |
| [archive/](./archive) | 이전 공동 스터디 자료 |

자동 업로드 폴더와 문제 README는 백준허브 형식을 따릅니다.
직접 쓰는 해설은 `notes/`에 남겨 재제출 이후에도 보관합니다.

## 한 문제의 학습 흐름

1. 입력 크기로 가능한 알고리즘과 복잡도를 가늠합니다.
2. C++로 구현하고 예제·경계값을 확인한 뒤 제출합니다.
3. 정답 제출 후 GitHub에 코드와 문제 설명이 올라왔는지 확인합니다.
4. 막혔던 문제를 [복습 목록](./notes/review.md)에 추가합니다.
5. 다음 복습에서는 기존 코드를 보지 않고 다시 구현합니다.
