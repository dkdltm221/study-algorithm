# 폴더 & 업로드 규칙

## 백준허브 설정

1. 연결 저장소가 의도한 개인 저장소인지 확인합니다. 현재 로컬 origin은 `dkdltm221/study-algorithm`입니다.
2. 디렉터리 옵션은 **언어별**을 사용합니다. 기존 `Java/프로그래머스/`, `MySQL/프로그래머스/` 경로와 같은 기준입니다.
3. C++로 한 문제를 정답 제출하고 GitHub에 코드와 README가 생성되는지 확인합니다.
4. 로컬 작업 전 `git pull --rebase`로 자동 업로드된 커밋을 가져옵니다. 커밋하지 않은 작업은 먼저 커밋하거나 보관합니다.

폴더 정리만으로 확장 프로그램 설정이 바뀌지는 않습니다.
저장소 이름은 유지해도 됩니다. 변경한다면 로컬 origin과 백준허브 연결을 함께 확인합니다.

[백준허브 공식 안내](https://github.com/BaekjoonHub/BaekjoonHub)

## 폴더 규칙

- 자동 업로드 경로와 문제 README는 직접 이름을 바꾸거나 옮기지 않습니다.
- 언어별 설정에서는 C++ 풀이가 `C++/` 아래에 생성됩니다. 하위 폴더·확장자는 백준허브가 정한 값을 사용합니다.
- 개인 해설은 `notes/boj-문제번호.md`, `notes/programmers-문제번호.md`에 작성합니다.
- 유형별로 코드를 옮기지 않고, 노트에 유형과 코드 링크를 남깁니다.
- 직접 만드는 폴더·파일 이름은 `lowercase-kebab-case`로 통일합니다.
- 이전 공동 스터디 자료는 `archive/legacy-study/`에서 보관합니다.
- 실행 파일과 로컬 `input.txt`, `output.txt`는 커밋하지 않습니다.
